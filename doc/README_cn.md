# 托盘输入法图标错位修复方案 (IME Tray Icon Fix)

在 Windows 10 / 11 的多语言输入环境下，系统托盘里的**输入法指示图标 (Input Indicator)** 会在「1 格 ↔ 2 格」之间切换宽度。由于托盘整体**右边缘锚定**、这个宽度变化会把指示图标左边的托盘图标整体平移，当系统开启了「**让每个应用窗口使用不同的输入法**」时，会导致你点托盘图标时**点到旁边的图标上**。

![修复前：点击托盘图标时输入法图标收缩，导致邻近图标平移，引发误点击](before-fix.gif)

---

## 问题：为什么会发生「误点击」

Windows 默认的通知区布局（从左到右，右边缘锚定）：

```text
  屏幕左端  <------------------------------------------------ 屏幕右边缘
  [通知折叠 ^]  |  [托盘图标]  |  [输入法指示图标]  |  [时钟]  |  [显示桌面]
```

注意**输入法指示图标正好卡在中间**——左边是托盘图标（SysPager），右边是时钟。当系统开启了「**让每个应用窗口使用不同的输入法**」且处于多语言环境（如 English / 中文 / 日本語）下时：

1. 在某个应用里输入时，指示图标常显示 **2 格**（如 `CH` + `中` 或 `JP` + `あ`），占位更宽。
2. 你点击某个托盘图标（如 Steam、WiFi）时，`WM_LBUTTONDOWN` 立刻把焦点切到 `explorer.exe`。
3. Windows Shell 默认回落到英文，指示图标收缩为 **1 格**（`ENG`）。
4. 因为右侧的时钟钉死在右边缘，收缩出来的宽度迫使**指示图标左边的所有内容整体向右平移**。
5. 等到 `WM_LBUTTONUP` 触发时，你瞄的那个图标已经挪走，点击落在了平移到光标下的相邻图标上。

---

## 修复方案

核心思路只有一个：**把输入法指示图标挪到通知区的第一个槽位**。于是其他一切图标都位于它的右侧、与屏幕右边缘保持固定距离，输入法指示图标宽度再怎么变也不会被推着平移。

![修复后：输入法图标固定到最左侧，右侧所有图标相对右边缘距离恒定，不再平移](after-fix.gif)

修复后的布局：

```text
  [输入法指示图标]  |  [通知折叠 ^]  |  [托盘图标]  |  [时钟]  |  [显示桌面]
```

## Windhawk Mod

[Windhawk](https://windhawk.net) 是一款开源的 Windows 自定义工具，Mod 以 `.wh.cpp` 源码形式分发，由它负责编译与注入。

这套思路在两个系统上实现方式完全不同（Win10 是命令式、无状态的 Win32 窗口重排；Win11 是声明式 XAML，直接改依赖属性由框架自行重排），因此拆成两个独立 Mod，不共享代码。

| 项目 | Windows 10 | Windows 11 |
| --- | --- | --- |
| 源文件 | `win10-ime-tray-icon-fix.wh.cpp` | `win11-ime-tray-icon-fix.wh.cpp` |
| 技术栈 | 纯 Win32（HWND / 窗口子类化） | XAML（WinRT） |
| Mod ID | `win10-ime-tray-icon-fix` | `win11-ime-tray-icon-fix` |
| 已测试版本 | 21H2 (Build 19044) | 24H2 |
| 用户设置 | 见下（3 种模式） | 无（仅开关控制） |

### Windows 10 Mod

提供三种模式，可单独或组合开启：

- **模式 1：移到最左侧（推荐）**——把指示图标放到通知区第一槽，左边内容随之右移，右侧图标不再平移。
- **模式 2：固定宽度**——强制指示图标始终占固定像素宽。36 ≈ 1 格，58 ≈ 1 格 + 附属图标，也可设 0 完全隐藏。
- **模式 3：隐藏附属输入法图标**——隐藏指示图标内的「中/英」或「あ/Ａ」按钮。

> 19042–19045（含 20H2、LTSC 2021）共用同一套二进制代码，应可正常工作；更早的 1903/1909 及以前理论上可行但未实测。

### Windows 11 Mod

只做一件事：把指示图标放到通知区第一槽，**没有任何用户设置项**，靠 Mod 开关控制。

- 宽度 / 间距：交给官方 Mod「Taskbar height and icon size」。
- 隐藏 IME 附属图标：交给官方 Mod「Taskbar tray system icon tweaks」。

> 跨版本（如不同 24H2 小版本）应可工作：Windows 11 把系统托盘逻辑分散在 `SystemTray.dll` / `Taskbar.View.dll` / `ExplorerExtensions.dll` 中，具体落在哪个 dll 取决于 Windows 版本，但逻辑/实现保持一致。
